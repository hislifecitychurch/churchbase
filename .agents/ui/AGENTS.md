# UI guidance entrypoint

Shared visual rules for every Churchbase application. Read the relevant reference before changing layout, spacing, or type:

- [Architecture index](architecture/_index.md) — references in this directory.
- [Spacing](architecture/spacing.md) — Tailwind spacing scale, rhythm, gutters, and touch targets.
- [Typography](architecture/typography.md) — type families, sizes, weight ceiling, and document titles.

The primitives themselves live in `packages/ui-w/`. Application composition rules live under [`.agents/app/`](../app/AGENTS.md).
