# Issue labels

Use GitHub’s native issue Type—Task, Bug, or Feature—to classify work. Reserve labels for recurring cross-cutting concerns. These `type:*` labels are legacy: do not add them to new issues; remove existing assignments as issues are migrated to native types.

| Label               | Color     | Use                                                             |
| ------------------- | --------- | --------------------------------------------------------------- |
| `type: feature`     | `#1D76DB` | Adds a product capability or user-facing workflow.              |
| `type: bug`         | `#D73A4A` | Fixes incorrect or broken existing behavior.                    |
| `type: maintenance` | `#6F42C1` | Chores, refactors, documentation, build, or configuration work. |

Add another label only when a recurring need justifies it. The repository’s default labels were removed; the existing Churchbase issues are labeled `type: feature`.
